# Dojo

**Don't test whether an AI agent can talk about money. Test whether it can be trusted with money.**

Dojo is an adversarial testing and evaluation framework for financial voice agents.

It generates synthetic financial worlds, simulates difficult debtor conversations, injects voice-recognition errors and faulty tool responses, and evaluates agents against deterministic ground truth.

Dojo identifies failure patterns, tests prompt improvements, and prevents regressions through statistical evaluation gates.

### Core capabilities

- Synthetic financial ledger generation
- Adversarial debtor simulation
- Voice-realistic ASR noise injection
- Deterministic financial and policy validation
- Agent evaluation and failure analysis
- Automated prompt optimization
- Reproducible regression testing

### Tech stack

Python · Pydantic · Hypothesis · LangGraph · Gemini · Next.js · TypeScript
